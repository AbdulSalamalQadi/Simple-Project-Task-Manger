# Simple Project Task Manager

A practical, hands-on project created as part of a **Git and GitHub workflow course**. The project demonstrates how to take a project from its initial local setup through collaborative review and a clean branch merge using Git and GitHub.

## About the Project

This repository serves both as a simple task-manager project and as a learning exercise in modern version-control practices. It follows the development lifecycle step by step, helping learners understand how everyday Git commands and GitHub collaboration features fit together in a real project.

## Workflow Demonstrated

- Create and initialize a project locally.
- Track changes and save progress with meaningful Git commits.
- Create a separate branch to work on a change.
- Push the branch to GitHub and open a pull request.
- Review the proposed changes before integrating them.
- Merge the approved branch into the main branch.

## Learning Goals

By following this repository, learners can gain practical experience with:

- Git repositories, staging, commits, and project history.
- Branch-based development and keeping work organized.
- Pushing and collaborating through GitHub.
- Pull requests, code review, and merging changes.
- A clear, repeatable workflow for managing changes safely.

## Purpose

The goal is to build confidence with the complete Git and GitHub process—not just individual commands. The project provides a small, approachable setting in which to practice making changes, reviewing them, and integrating them into the main line of development.
